1 Install Python

ขั้นที่ 1 — ติดตั้ง Python + ไลบรารี

  1. ติดตั้ง Python จาก python.org/downloads → ตอนติดตั้ง ติ๊ก "Add Python to PATH"
  2. เปิด Command Prompt (กดปุ่ม Windows → พิมพ์ cmd) แล้วรันคำสั่งนี้:
pip install pdfplumberคัดลอก
ถ้าไม่รู้จัก pip ลอง python -m pip install pdfplumber หรือ py -m pip install pdfplumber

ขั้นที่ 2 — ตั้งโฟลเดอร์ไฟล์บิล

โฟลเดอร์ที่มีโฟลเดอร์ปี (2024, 2025, …) อยู่ข้างใน — คัดลอก path จาก File Explorer มาวาง
โฟลเดอร์ที่เก็บรูปแคปหน้าปันผลจากมือถือ (ไว้ใช้ตอนทำฟีเจอร์ปันผล)
โฟลเดอร์ไฟล์ยืนยันการซื้อขายทอง — parser จะอ่านทองจากที่นี่เพิ่มจาก Confirmation Notes
ไฟล์ใหม่วางที่ root ของ Confirmation Notes → หลัง parse จะถูกย้ายเข้า yyyy/Offshore หรือ yyyy/Mutual Fund · ปิดได้ถ้าอยากจัดเอง
ไฟล์ config.json ที่จะได้:
Chrome/Edge: เด้ง Save As → เลือกโฟลเดอร์ scripts\ → Save · Firefox: ดาวน์โหลดแล้วย้ายเข้า scripts\ เอง
config.json เก็บแค่ path ไม่เก็บรหัส PDF (รหัสพิมพ์ตอนรันทุกครั้ง ไม่ถูกบันทึก)

ขั้นที่ 3 — รันตัวอ่านไฟล์

  1. ดับเบิลคลิก scripts\run_wealthman.bat
  2. พิมพ์รหัส PDF เมื่อถาม แล้ว Enter (พิมพ์แล้วไม่เห็นตัวอักษร = ปกติ)
  3. parser จะอ่านไฟล์ทั้งหมด → สร้างข้อมูล → เปิด dashboard ให้อัตโนมัติ
หรือรันผ่าน Command Prompt เองก็ได้:
python scripts\parse_investments.pyคัดลอก

ขั้นที่ 4 — เสร็จสิ้น

กำลังตรวจสอบข้อมูล…

เวลามีไฟล์ใหม่มา: ดับเบิลคลิก scripts\run_wealthman.bat อีกครั้ง → ข้อมูลอัปเดต (ไม่ต้องตั้งค่าใหม่)

เริ่มต้นใช้งาน

ภาพรวมระบบ — ทำงานยังไง

ส่วนทำอะไรทำงานเมื่อ
1. Google Apps Script (cloud)ดึง PDF ใบยืนยันจาก Gmail → เซฟลงโฟลเดอร์ root ของ Confirmation Notes (inbox รอประมวลผล)อัตโนมัติทุกวัน ~01:00
2. parse_investments.py (เครื่อง)อ่าน PDF ทุกไฟล์ → ดึงรายการซื้อขาย → สร้างไฟล์ข้อมูล → ย้ายไฟล์เข้า ปี/ชนิดกดรัน run_wealthman.bat
ไฟล์ PDF ติดรหัส — parse_investments.py ถอดรหัสตอนอ่านเท่านั้น ไม่แตะเนื้อไฟล์ต้นฉบับ และไม่เก็บรหัสลงไฟล์
โครงสร้างโฟลเดอร์: ไฟล์ใหม่อยู่ที่ root (= ยังไม่ประมวลผล) · หลัง parse สำเร็จจะถูกย้ายเข้า yyyy/Offshore หรือ yyyy/Mutual Fund อัตโนมัติ (เปิด/ปิดได้ที่ Settings)

การใช้งานประจำ

1เวลามีไฟล์ใหม่มา (flow อัตโนมัติ)

  1. Apps Script ดึงไฟล์ใหม่จาก Gmail ลงที่ root ของ Confirmation Notes อัตโนมัติทุกวัน (~01:00) — ไฟล์ที่ root = ยังไม่ประมวลผล
  2. รัน parser: ดับเบิลคลิก scripts\run_wealthman.bat
  3. พิมพ์รหัส PDF เมื่อถาม (พิมพ์แล้วไม่เห็นตัวอักษร = ปกติ)
  4. parser อ่านข้อมูล → อัปเดต dashboard → ย้ายไฟล์ที่ root เข้า yyyy/Offshore หรือ yyyy/Mutual Fund ตามปี+ชนิดในเอกสาร
  5. ไฟล์ที่ย้ายแล้ว = ประมวลผลเรียบร้อย · ดูว่าย้ายอะไรไปไหนได้ใน scripts\run_log.txt
กันพลาด: ย้ายเฉพาะไฟล์ที่ parse สำเร็จ + รู้ปี/ชนิดชัด · ปี/ชนิดไม่ชัด → ปล่อยไว้ที่ root · ชื่อซ้ำปลายทางเติม _2 ไม่ทับ · รายการกันซ้ำด้วย txn_id อยู่แล้ว (ย้ายไฟล์ไม่กระทบข้อมูล)
ปิดการย้ายอัตโนมัติได้ที่ Settings (เอาเครื่องหมายถูก "ย้ายไฟล์เข้าปี/ชนิด" ออก) — ไฟล์จะค้างที่ root ให้จัดเอง

⚡2 โหมดการรัน: ปกติ (เร็ว) vs rebuild (อ่านใหม่ทั้งหมด)

parser อ่านไฟล์แบบ 2 โหมด เพื่อไม่ให้เปิดไฟล์เก่าซ้ำทุกครั้ง (ยิ่งไฟล์เยอะยิ่งช้า)
โหมดไฟล์ที่ดับเบิลคลิกอ่านอะไรใช้เมื่อ
ปกติ (เร็ว)scripts\run_wealthman.batเฉพาะ PDF ที่ root (ไฟล์ใหม่) + โหลดข้อมูลเก่าจาก inv_data_full.jsทุกวัน เวลาไฟล์ใหม่มา
rebuildscripts\run_wealthman_rebuild.batทุกไฟล์ (root + ทุกโฟลเดอร์ปี) อ่านสดใหม่หมดแก้ parser (เพิ่ม field) · สงสัยข้อมูลเพี้ยน · inv_data_full.js หาย

โหมดปกติทำงานยังไง:

  1. โหลดรายการเก่าจาก data\inv_data_full.js (ที่เคย parse ไว้)
  2. อ่าน PDF เฉพาะที่ root เท่านั้น (ไฟล์ใหม่ที่ยังไม่ย้ายเข้าปี) — ไฟล์ใน yyyy/ ไม่ถูกเปิดซ้ำ
  3. รวมเก่า+ใหม่ กันซ้ำด้วย txn_id + order_no → เขียนไฟล์ข้อมูล → ย้ายไฟล์ root เข้าปี/ชนิด
ตาข่ายนิรภัย: ถ้ายังไม่มี inv_data_full.js (เช่นเครื่องใหม่/ลบไป) → โหมดปกติจะ auto-rebuild อ่านทุกไฟล์ให้เองครั้งแรก ไม่ต้องสั่ง rebuild
รันผ่าน Command Prompt ก็ได้: run_wealthman.bat (ปกติ) หรือ run_wealthman.bat rebuild (อ่านใหม่ทั้งหมด) — ไฟล์ run_wealthman_rebuild.bat คือตัวเดียวกับการพิมพ์ rebuild ต่อท้าย เผื่อสะดวกดับเบิลคลิก

💰วิธี log เงินปันผล (Dividends)

ปันผลไม่มีเอกสารส่งทางเมล — ต้องแคปหน้าจอจากแอป Dime บนมือถือเอา แล้วเอาเข้าระบบ

ขั้นตอนทั้งหมด:

  1. แคปหน้าปันผลจากแอป Dime บนมือถือ (หน้า Activity / Dividend) — แคปให้เห็น header เดือน + รายการ Dividend และ Withholding Tax ครบ · แคป 1 รูป = 1 เดือน อย่าให้เดือนปนกันในรูปเดียว (ถ้าเดือนนั้นรายการยาวเกินจอ ค่อยแคปเพิ่มเป็นรูปที่ 2 ของเดือนเดิม)
  2. เซฟรูปเข้าโฟลเดอร์ G:\My Drive\Documents\Investment\Dime\Dividend (path นี้ตั้งไว้ในแท็บ Settings ช่อง "โฟลเดอร์รูปปันผล")
  3. แปลงรูปเป็นข้อมูล — เลือก 1 ใน 2 วิธี:
    • วิธี A — กรอกผ่าน Template (ไม่พึ่งใคร): ไปแท็บ 💰 Dividends → กด Template ได้ไฟล์ Excel เปล่า → กรอกข้อมูลจากรูป (จะพิมพ์เอง หรือใช้ OCR ตัวไหนช่วยก็ได้) → กด Import เลือกไฟล์ที่กรอก → ระบบรวมให้อัตโนมัติ (กันซ้ำด้วย หลักทรัพย์ + วันจ่าย)
    • วิธี B — ให้ผู้ช่วย AI อ่านให้: เปิดแชทผู้ช่วย แล้วบอกให้อ่านรูปในโฟลเดอร์ Dividend → ได้ข้อมูลกลับมา (แม่นกว่า OCR ทั่วไป แต่ต้องมีผู้ช่วย)
  4. ตั้งชื่อรูป + ย้ายเข้า Logged — รูปที่ log เข้าระบบแล้ว เปลี่ยนชื่อตามเดือนที่อยู่ในรูป (ดูหัวข้อถัดไป) แล้วย้ายเข้าโฟลเดอร์ Dividend\Logged

กฎการตั้งชื่อรูป (สำคัญ — เพื่อรู้ว่า log ถึงเดือนไหนแล้ว):

  • ตั้งชื่อตาม เดือนที่อยู่ในรูปจริง (header เดือนในภาพ) ไม่ใช่ชื่อ IMG จากกล้อง หรือลำดับไฟล์

ภาษี

🧾ภาษีเงินได้จากหุ้นต่างประเทศ (สำหรับผู้อยู่ไทย)

ข้อมูลสรุปเพื่อความเข้าใจเบื้องต้น — ไม่ใช่คำแนะนำทางภาษี กฎหมายเปลี่ยนได้ ควรปรึกษานักบัญชี/ผู้เชี่ยวชาญก่อนยื่นจริง

หลักสำคัญ: ไทยเก็บภาษีเงินได้ต่างประเทศแบบ "ตามการนำเงินเข้า" (remittance) — ไม่ใช่ตอนที่กำไรเกิดในต่างประเทศ แต่ตอนที่โอนเงินกลับเข้าไทย

เงินได้ต่างประเทศจะถูกเก็บภาษีก็ต่อเมื่อครบ 2 เงื่อนไขพร้อมกัน:

  1. คุณเป็นผู้มีถิ่นที่อยู่ในไทยทางภาษี ในปีที่เงินได้นั้นเกิด — คืออยู่ในไทย ตั้งแต่ 180 วันขึ้นไป ในปีปฏิทินนั้น (นับสะสม ไม่ต้องติดกัน)
  2. คุณนำเงินนั้นเข้าไทย — จะปีเดียวกับที่ได้ หรือปีไหนก็ตามหลังจากนั้น
ถ้าขาดข้อใดข้อหนึ่ง ก็ยังไม่ถูกเก็บ · ภาษีจะคิดในปีที่นำเงินเข้า ไม่ใช่ปีที่ได้กำไร

เส้นแบ่งสำคัญ: ก่อน vs หลัง 1 ม.ค. 2024

  • เงินได้ที่เกิดตั้งแต่ 1 ม.ค. 2024 เป็นต้นไป (ตามแนวปฏิบัติ ป.161/2566) → นำเข้าไทยเมื่อไหร่ก็ต้องนำมารวมคำนวณภาษี ไม่ว่าจะข้ามปีหรือไม่
  • เงินได้ที่เกิดก่อน 1 ม.ค. 2024 (ตามแนวปฏิบัติ ป.162/2566) → ยกเว้น นำเข้าไทยตอนไหนก็ไม่ถูกเก็บ
💡 เก็บหลักฐานแยก เงินก่อนปี 2024 ออกจาก เงินได้หลังปี 2024 (เช่น statement ณ 31 ธ.ค. 2023) — ถ้าเงินปนกันในบัญชีเดียว จะพิสูจน์ส่วนที่ยกเว้นได้ยาก

หุ้นนอกของคุณเข้าข่ายยังไง (Dime offshore):

  • กำไรจากการขาย (capital gain) + เงินปันผล (dividend) = เงินได้ต่างประเทศ → จะเสียภาษีไทยเมื่อโอนเงินกลับเข้าไทย (ตามเงื่อนไขด้านบน) · ตราบใดที่เงินยังอยู่ในพอร์ต/บัญชีต่างประเทศ ยังไม่โอนเข้าไทย = ยังไม่ถึงจุดเก็บ
  • ปันผลที่ถูกหักภาษีสหรัฐไว้แล้ว (wht_usd ปกติ 15% ตามสนธิสัญญาภาษีซ้อนไทย–สหรัฐ) → ภาษีที่ถูกหักที่สหรัฐ ใช้เป็นเครดิตหักออกจากภาษีไทยได้ กันเก็บซ้ำซ้อน
ถ้าต้องยื่น: เงินได้ต่างประเทศที่นำเข้าไทยยื่นในแบบ ภ.ง.ด.90 (ยื่นช่วง ม.ค.–มี.ค. ของปีถัดไป) · เตรียมหลักฐานการหักภาษี ณ ที่จ่ายของสหรัฐไว้ใช้ขอเครดิตภาษี

แอปนี้ช่วยอะไร:

  • แท็บ Tax Report สรุปกำไร/ขาดทุนจากการขายรายปี + ปันผลรับรายปี (gross/หักภาษี/สุทธิ) + ภาษีสหรัฐที่ถูกหัก (wht_usd) → ใช้เป็นตัวเลขตั้งต้นประกอบการยื่น
  • Export Excel ได้หลายชีต (รายปี/รายหลักทรัพย์/ปันผล) ส่งให้นักบัญชีได้เลย
⚠️ ตัวเลขในแอปคิดตามวันทำรายการ (ซื้อ/ขาย/จ่ายปันผล) ซึ่งใช้ดูผลตอบแทน — แต่ฐานภาษีไทยยึดตามวันที่นำเงินเข้าไทย ซึ่งแอปไม่ทราบ (ขึ้นกับว่าคุณโอนกลับเมื่อไหร่) จึงต้องปรับให้ตรงกับการโอนจริงเองตอนยื่น
หมายเหตุสถานะกฎหมาย: มีการพูดถึงร่างผ่อนปรน (ยกเว้นถ้านำเข้าปีเดียวกับที่ได้ หรือปีถัดไป) แต่ ณ ปี 2026 ยังเป็นแค่ร่าง ยังไม่ประกาศใช้ — ให้ยึดกฎ ป.161/162 ที่ใช้อยู่จนกว่าจะมีประกาศจริง
